# Java Small Projects Collection

Welcome to my **Java Small Projects** repository!  
This is where I share the small Java console programs I make while learning and practising Java.  
Each project is simple, fun, and helps me improve my coding skills one step at a time.  

---

## 🧩 Projects in this Repository

### 1. [💰 Banking System](https://github.com/iamjunnaid/Java_Projects/tree/master/BankingSystem)
A small console-based banking system.  
You can check your balance, deposit money, withdraw safely, and exit the system.

**Features**
- Show current balance  
- Deposit and withdraw money  
- Input validation  
- Exit safely  

---

### 2. [🧠 Guessing Game](https://github.com/iamjunnaid/Java_Projects/tree/master/GuessGame)
A fun quiz game that asks multiple-choice questions and shows your score at the end.  

**Features**
- 5 quiz questions  
- Correct/incorrect answer feedback  
- Final score summary  

---

### 3. [✊🖐✌ Rock, Paper, Scissors](https://github.com/iamjunnaid/Java_Projects/tree/master/RockPaperScissors)
A simple game where you play Rock, Paper, Scissors against the computer!  

**Features**
- Random computer moves  
- Input validation  
- Play as many rounds as you want  
- Friendly end message  

---

### 4. [🎰 Slot Machine](https://github.com/iamjunnaid/Java_Projects/tree/master/SlotMachine)
A mini slot machine game written in Java.  
You start with £100, place bets, spin 3 symbols, and win payouts based on matching symbols.  

**Features**
- Betting system  
- Random 3-symbol spin  
- Payouts for matching symbols  
- Play again or quit anytime  

---

### 5. [🎵 Audio Player](https://github.com/iamjunnaid/Java_Projects/tree/master/AudioPlayer)
A small console-based audio player in Java.
You can play, stop, reset, and quit a .wav audio file using keyboard commands.

**Features**
- Play audio files (.wav format)
- Stop playback anytime
- Reset audio to the beginning
- Quit the player gracefully

---

### 6. 🪓 [Hangman Game](https://github.com/iamjunnaid/Java_Projects/tree/master/Hangman)
A simple console-based Hangman game in Java.  
The computer randomly chooses a word, and you must guess the letters before the hangman is fully drawn.

**Features**
- Reads random words from a file  
- Tracks correct and wrong guesses  
- Displays hangman progress visually  
- Ends after 6 wrong attempts
