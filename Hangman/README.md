# 🪓 Java Hangman Game

A simple **console-based Hangman game** written in Java.  
The program randomly picks a word from a text file, and you have to guess the letters before the hangman is fully drawn!

---

## 🚀 Features
- Reads words from a file (`words.txt`)
- Randomly selects a new word each game  
- Tracks wrong guesses and draws the hangman step-by-step  
- Simple text-based interface  
- Ends game after 6 wrong guesses  

---

## 🧰 Technologies Used
- **Language:** Java 21  
- **Libraries:** java.io, java.util  
- **IDE:** VS Code / IntelliJ IDEA / Eclipse
